# 💻 Cursor IDE – CrowLLM Integration

Cursor is an AI-powered code editor built on VS Code. Connect it to CrowLLM for enhanced coding assistance.

## Configuration Steps

1. Open **Cursor Settings** (Ctrl+, or Cmd+,)
2. Go to **Cursor Settings** → **Models**
3. Scroll to **OpenAI API Key** section
4. Click **Override OpenAI Base URL**
5. Enter the following:

```text
Base URL: https://crowllm.com/v1
API Key: YOUR_API_KEY
```

6. Select your preferred model from the dropdown

## Recommended Models for Coding

- **Claude Sonnet 4.5**: Best for complex code generation and refactoring
- **GPT-4o**: Fast and accurate for most coding tasks
- **Claude Opus 4.7**: Best for architectural decisions and code reviews
- **DeepSeek Coder**: Specialized for coding tasks

## Available Models

CrowLLM supports 40+ AI models including:

- **Claude**: `claude-opus-4-7`, `claude-sonnet-4-5`, `claude-haiku-4`
- **GPT**: `gpt-4o`, `gpt-4-turbo`, `gpt-3.5-turbo`
- **DeepSeek**: `deepseek-chat`, `deepseek-coder`

Get your API key at [crowllm.com/keys](https://crowllm.com/keys)
