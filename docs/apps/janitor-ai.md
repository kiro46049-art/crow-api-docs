# 📢 Janitor AI – CrowLLM Integration Guide

Follow these steps to connect Janitor AI with CrowLLM:

## 1. Start Chat
Select any character from the Janitor AI homepage and open the chat.

## 2. Open Menu
Inside the chat screen, click the **☰ (top-right menu)** icon.

## 3. API Settings
Go to **API Settings** from the menu.

## 4. Configure Proxy
Enable Custom/Proxy settings and enter the following:

```text
Provider: CrowLLM
Model: Choose any available model (e.g., claude-sonnet-4-5, gpt-4o)
Base URL: https://crowllm.com/v1/chat/completions
API Key: YOUR_API_KEY
```

## 5. Test Connection
Send a message to verify the connection is working.

## Available Models

CrowLLM supports 40+ AI models including:

- **Claude**: `claude-opus-4-7`, `claude-sonnet-4-5`, `claude-haiku-4`
- **GPT**: `gpt-4o`, `gpt-4-turbo`, `gpt-3.5-turbo`
- **Gemini**: `gemini-2.0-flash-exp`, `gemini-1.5-pro`

Get your API key at [crowllm.com/keys](https://crowllm.com/keys)
