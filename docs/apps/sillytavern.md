# 📢 SillyTavern – CrowLLM Setup (Quick Guide)

## Configuration Steps

1. Open your SillyTavern instance.
2. Click the **🔌 plug icon** (top bar, first icon on the right).
3. Go to **Chat Completion Source**.
4. Select **Custom (OpenAI-compatible)**.
5. Set the following:

```text
Base URL: https://crowllm.com/v1
API Key: YOUR_API_KEY
Model: Choose any available model (e.g., claude-sonnet-4-5, gpt-4o)
```

6. Click **Connect** to test the connection.

## Recommended Models for Roleplay

- **Claude Opus 4.7**: Best for creative, nuanced conversations
- **Claude Sonnet 4.5**: Great balance of quality and speed
- **GPT-4o**: Fast and coherent responses
- **Gemini 2.0 Flash**: Budget-friendly option

## Available Models

CrowLLM supports 40+ AI models including:

- **Claude**: `claude-opus-4-7`, `claude-sonnet-4-5`, `claude-haiku-4`
- **GPT**: `gpt-4o`, `gpt-4-turbo`, `gpt-3.5-turbo`
- **Gemini**: `gemini-2.0-flash-exp`, `gemini-1.5-pro`

Get your API key at [crowllm.com/keys](https://crowllm.com/keys)

## Advanced Settings

### Context Size
Set according to your chosen model:
- Claude Opus 4.7: 200,000 tokens
- Claude Sonnet 4.5: 200,000 tokens
- GPT-4o: 128,000 tokens

### Streaming
Enable streaming for real-time responses.
